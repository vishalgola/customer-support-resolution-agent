# Return Processing (synthetic)

## 1. Return statuses
A return moves through requested, in transit, and received. Only a return marked received can lead to a refund.

## 2. Inspection
After a return is received, the warehouse inspects the item. Inspection checks that the item matches the order and has no damage beyond normal use.

## 3. Inspection outcomes
An inspection ends as passed or failed. A failed inspection means no refund is issued and the case goes to a reviewer.
