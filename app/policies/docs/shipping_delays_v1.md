# Shipping Delays (synthetic)

## 1. What counts as a delay
An order is delayed when it has not been delivered 7 days after it shipped.

## 2. What support can do
For a delayed order, share the latest tracking information with the customer. No refund is issued while the package is still in transit.

## 3. Lost packages
If an order has not been delivered 14 days after it shipped, it is treated as possibly lost and must be escalated to a reviewer.
