# Exceptions (synthetic)

## 1. Cases that must go to a reviewer
Escalate to a reviewer when the return arrived after the return window, when order or return records conflict or are missing, or when the customer disputes an inspection result.

## 2. Unconfirmed refunds
If a refund has an unconfirmed outcome, do not issue another refund. The case is reconciled with the payment provider first.
